# API 變更記錄（前後端交接）

前端、後端在不同對話裡開發，這份文件是兩邊的**交接記錄**。

- **後端**：每次新增、修改、刪除 API，在最上面加一筆，並重新匯出 `docs/api/openapi.json`。
- **前端**：每次開始工作先看這裡，然後重新生成類型。
- 需要對方配合的事，標註 **【待前端】** 或 **【待後端】**，完成後改成 **【已完成】**。

格式：

```
## YYYY-MM-DD
- 【新增 / 修改 / 刪除】METHOD /api/xxx：說明
  - 前端要做什麼：……
```
